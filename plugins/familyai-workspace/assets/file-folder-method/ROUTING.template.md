# FamilyAI Workspace Router

Use this file as the map for `~/AI`. Enter the relevant folder and read its `AGENT.md` when it has one.

| Need | Folder | Purpose |
|---|---|---|
| Work on an ongoing project | [Projects](./Projects/) | One folder per project |
| Read or add journal records | [Journal](./Journal/) | Journal index, entries, and journal state |
| Give the assistant a file | [FILE-IN](./FILE-IN/) | Incoming files to process |
| Retrieve completed work | [FILE-OUT](./FILE-OUT/) | Finished deliverables |
| Learn or copy the folder method | [FileFolderMethod](./FileFolderMethod/) | Guide and project templates |

If a task does not fit, start in [Projects](./Projects/) and create a clearly named project folder rather than scattering files across the workspace root.
